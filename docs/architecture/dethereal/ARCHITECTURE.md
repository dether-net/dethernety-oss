# Dethereal MCP Server Architecture (Superseded)

This page held a snapshot of the pre-upgrade Dethereal MCP server (version `2.0.0`, 12 tools). That server no longer exists, and the snapshot is retired. The current server and its 30 tools are described in [MCP_ARCHITECTURE.md](MCP_ARCHITECTURE.md); the skills, agents, hooks, bundles and installer around it are described in [PLUGIN_ARCHITECTURE.md](PLUGIN_ARCHITECTURE.md). The decisions that took the server from the old design to the current one, with their rationale, are recorded in [DECISIONS.md](DECISIONS.md).
