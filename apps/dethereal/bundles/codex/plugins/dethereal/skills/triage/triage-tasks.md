# Triage: the remediation task list

Only after the summary of a run whose knowledge graph was present, when the run applied at least one affirm and the operator answered `yes`. It uses only what this run already holds — no new analysis, no new platform sweep.

1. **Its findings**: those this run affirmed **and applied**, on groups whose knowledge-graph tier was read (before any latch). The source material: their evaluations and deltas, the dossiers' source paths, the analyst's `source:<file:line>` citations, and the authored tier's corpus fields. The only new reads: `mcp__dethereal__get_class_guide`, once per (class, attribute keys) set. A data flow's class id comes from its attribute file (`classData.id`) when the group's members do not give it (`element_class_id`).
2. **Per element**: merge the deltas of the element's affirmed findings, each annotated with the findings whose trigger it would change — framed as of this run, never as settling a finding. Where a delta's `sufficientAlone` is false, add `insufficient alone — condition group <N> also holds`.
3. **The document** — the header, one section per element, then the tails:
   - The header, each line exactly once: `Task list derived from the threat model's attributes as of <date>; applying changes alters the model — re-run analysis and triage to confirm.` and `Citations reflect how the underlying exposure was authored, not the strength, severity, or priority of the finding. Absence of a citation is not absence of basis.`
   - Per element: (a) the merged deltas, with their sufficiency lines; (b) where in the repository — the element's discovery source files and the analyst's `source:<file:line>` citations; (c) how to verify — the class guide's `howToObtain` steps and `typicalValues`, quoted as written: each field whole, as its own line (a `- ` or `> ` line), exactly as `mcp__dethereal__get_class_guide` returned it, cleaned like any platform text (a quote the cleaning or a redaction changed is checked as your own words; an empty guide leaves the block out); (d) candidate controls, by attribute overlap between the deltas and the countermeasure rules of the chains read — **never by technique match** — each labelled `candidate`, split into *mitigate* (the exposure rules' deltas) and *detect* (countermeasure-rule candidates), an empty side stated, never invented, and never phrased as the control that settles a technique; (e) the finding's corpus citations (`kind`, `id`, `canonicalUrl`, a one-line synthesis).
   - The tails: **previously affirmed** — findings affirmed in earlier runs, by name and element, each with `re-run triage to extract full detail`; **not derivable** — findings this run affirmed without knowledge-graph coverage, by name and element. Nothing is dropped silently.
   - Compose it without these words in your own text, noun forms included: addresses, closes, fixes, reduces, resolves, mitigates, lowers risk, moves to residual, planned-fixed, remediated, scheduled.
4. **Check and write in one call.** `mcp__dethereal__triage_review` `tasks` with `directory_path`, `run` (the scratch directory's name), the composed text, and `guides`: each (class, element kind, attribute keys) whose `mcp__dethereal__get_class_guide` text the list quotes. Never write the list, or any draft of it, with your edit tool or the shell.
   - `claims_found`: nothing was written. Say "Remediation task list: not written — it holds words the check refuses:" and quote the terms. A listed word in composed text is a fault of the composition, and a quoted source or a platform name can hold one too. Never edit the text, least of all the run's data (rule, exposure and control names appear as they are, or not at all), to get past the check.
   - `text_invalid`: the characters it names are emoji, tabs or invisible characters in your composition. Compose it once more without them and call again — never to get past the claims check; a second refusal: as any other.
   - Written: name its `path`.
   - `tasks_exist`: show it as returned. A file is at the path that this call did not write or check; never call it the task list, and never say nothing is there. Then show the document in the conversation.
   - Any other refusal: show it as returned. Then show the document in the conversation instead, saying it was not written; the platform writes are already done, so nothing is lost.
